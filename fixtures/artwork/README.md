# Fixtures de artwork

Todo el arte de esta carpeta es original y fue creado para BPSteamFit como
material de demostración. No se copió arte de SteamGridDB, IGDB, RAWG ni de
ningún juego comercial.

- Los archivos `.svg` son las fuentes editables.
- Los `.png` se generaron con `sharp` a partir de esos SVG.
- `example-quest-*` acompaña al juego ficticio `Example Quest` del proveedor mock.
- Las dimensiones coinciden con las variantes soportadas: portrait 600x900,
  hero 1920x620, logo 1000x400 con transparencia, icon 256x256 y screenshots
  1280x720.

Licencia: material del proyecto BPSteamFit, uso local de demostración. No se
distribuye como arte oficial de ningún juego.
